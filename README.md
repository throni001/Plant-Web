# Plant-Web 🌱

A plant recommendation and e-commerce website built with **Bootstrap 5**. Find your perfect plant based on sunlight, care level, and pet-friendliness.

## Features

- **Plant Recommendations** – Interactive quiz to find your ideal plant
- **Product Catalog** – Browse popular houseplants and curated collections
- **Photo Gallery** – Visual collage of plant inspiration
- **Care Guides** – Embedded video tutorials for plant care
- **Responsive Design** – Fully responsive with Bootstrap 5

## Pages

| Page       | Description                          |
|------------|--------------------------------------|
| Home       | Landing page with quiz & gallery     |
| Products   | Product catalog                      |
| About      | About Blooming Oasis                 |
